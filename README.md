# Транслятор учебного конфигурационного языка в TOML (Вариант 25)

## 1. Общее описание
Инструмент командной строки для преобразования текста из учебного конфигурационного языка в формат TOML. Синтаксический разбор реализован с помощью библиотеки **Lark** (алгоритм LALR).

## 2. Описание всех функций и настроек
* `src/grammar.py` — описание формальной грамматики языка (`CONFIG_GRAMMAR`).
* `src/parser.py` — разбор входного текста (`parse_config`) и вычисление константных выражений (`ConfigTransformer`: поддержка `+` и `sort()`).
* `src/toml_serializer.py` — сериализация результирующего словаря в формат TOML (`to_toml`).
* `src/cli.py` — обработка аргументов командной строки (`-i` / `--input`) и вывод результата в `stdout` или диагностических сообщений в `stderr`.

### Параметры командной строки
* `-i`, `--input` — путь к входному файлу на учебном конфигурационном языке (обязательный параметр).

## 3. Команды для сборки проекта и запуска тестов
Установка зависимостей:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запуск тестов:
```bash
pytest -v
```

## 4. Примеры использования
Трансляция конфигурации веб-сервера:
```bash
./run.sh -i examples/server_config.conf
```

Трансляция игрового баланса:
```bash
./run.sh -i examples/game_balance.conf
```
